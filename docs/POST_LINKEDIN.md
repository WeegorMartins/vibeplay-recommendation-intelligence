# Texto sugerido para publicar o case

Construí um sistema de recomendação de ponta a ponta inspirado em problemas de descoberta de conteúdo de plataformas de streaming.

O desafio não era apenas prever o próximo título. Era equilibrar relevância, diversidade, cobertura do catálogo, cold start e explicabilidade — sem confundir uma boa métrica offline com resultado de negócio.

A solução combina filtragem colaborativa, atributos de conteúdo, popularidade e frescor. Depois do ranking, um re-ranking MMR reduz repetição. O projeto também inclui dataset sintético, split temporal, baseline, API, chatbot analítico, dashboard HTML responsivo, testes, guardrails e automação com GitHub Actions.

O ponto que considero mais importante: o modelo é um candidato. A recomendação de implementação vem acompanhada de um A/B test, com horas assistidas como métrica primária e skips, latência e concentração como guardrails.

Stack: Python, pandas, scikit-learn, FastAPI, HTML, CSS, JavaScript, Plotly e GitHub Actions.
